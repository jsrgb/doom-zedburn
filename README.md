# Doom Zedburn

A Zed port of [zenburn-emacs](https://github.com/bbatsov/zenburn-emacs).

## Install

In Zed, choose **Extensions → Install Dev Extension**, select this directory, then choose **Doom Zedburn** from the theme selector.
